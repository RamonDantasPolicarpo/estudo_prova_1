Pilha (Stack): Último a Entrar, Primeiro a Sair

O conceito mais fundamental de estrutura de dados — e como Python implementa com listas.

🧠 O Conceito

Uma pilha é uma estrutura de dados onde o último elemento inserido é o primeiro a ser removido. Isso se chama LIFO — Last In, First Out.

Analogia do mundo real Pense em uma pilha de pratos. Você coloca um prato em cima do outro. Quando vai pegar um, pega sempre o de cima — o último que colocou.

As duas operações fundamentais são:

OperaçãoO que fazEm Python (list)Em Java (Stack)
Push (empilhar)Coloca no topopilha.append(x)stack.push(x)
Pop (desempilhar)Remove do topo e retornapilha.pop()stack.pop()
🔶 Conexão com Java Em Java você usa Stack<Integer> com push() e pop(). Em Python, uma list simples faz o mesmo papel — append() é o push, pop() é o pop. O nome muda, o conceito é idêntico.

👁️ Visualizando

append(10) append(20) append(30) pop() ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │ │ │ │ │ 30 │ ←topo │ │ → retorna 30 │ │ │ 20 │ │ 20 │ │ 20 │ ←topo │ 10 │ │ 10 │ │ 10 │ │ 10 │ └──────┘ └──────┘ └──────┘ └──────┘ pilha=[10] pilha=[10,20] pilha=[10,20,30] pilha=[10,20]

O pop() sempre remove o último elemento da lista — que é o topo da pilha.

💻 Sintaxe Python Essencial

Criando e manipulando uma pilha

# Criar pilha vazia
pilha = []

# Empilhar (push)
pilha.append(10)   # pilha = [10]
pilha.append(20)   # pilha = [10, 20]
pilha.append(30)   # pilha = [10, 20, 30]

# Desempilhar (pop) — remove E retorna o topo
topo = pilha.pop()  # topo = 30, pilha = [10, 20]
print(topo)          # Saída: 30

Invertendo com pilha

texto = "DADOS"
pilha = []

# Empilha cada letra: D, A, D, O, S
for letra in texto:
    pilha.append(letra)

# Desempilha: S, O, D, A, D (invertido!)
invertido = ""
while pilha:           # enquanto pilha NÃO estiver vazia
    invertido += pilha.pop()

print(invertido)       # Saída: SODAD
💡 Dica de sintaxe while pilha: em Python significa "enquanto a lista não estiver vazia". Uma lista vazia [] é considerada False. Em Java seria while (!stack.isEmpty()).

O que range(1, 5) gera?

# range(1, 5) gera: 1, 2, 3, 4  (NÃO inclui o 5!)
for i in range(1, 5):
    pilha.append(i)
# pilha = [1, 2, 3, 4]

# Desempilhar tudo imprime na ordem inversa
while pilha:
    print(pilha.pop(), end=" ")
# Saída: 4 3 2 1
Sobre end=" " Em Python, print() por padrão pula linha. end=" " troca a quebra de linha por um espaço, então tudo fica na mesma linha: 4 3 2 1.

🌍 Onde Pilha Aparece no Mundo Real

  • Ctrl+Z (Desfazer): cada ação é empilhada; desfazer faz pop da última ação
  • Parênteses balanceados: ao ler ( empilha; ao ler ) desempilha. Se no final a pilha estiver vazia, está balanceado
  • Recursão: cada chamada de função é um "frame" empilhado na call stack da máquina
  • Notação pós-fixa: calculadoras HP usam pilha — empilha operandos, operador faz pop de dois e empilha o resultado

📦 Pilha em Vetor vs Pilha Ligada

AspectoVetor (array/list)Ligada (linked list)
Limite de tamanhoEstático — pode estourar se o vetor encherDinâmico — cresce conforme necessário
Contador de tamanhoUsa len()Pode ter contador para check rápido
MemóriaContíguaEspalhada (cada nó aponta pro próximo)
⚠️ Do Kahoot "Por que pilha em vetor pode estourar mais cedo?" → Porque tem limite estático (tamanho fixo do array). Em Python a list cresce automaticamente, mas conceitualmente a resposta é essa.

🎯 Teste Seu Conhecimento

1. Qual dessas estruturas é LIFO?

  • Pilha
  • Fila
  • Lista encadeada
  • Árvore binária
✅ Correto! Pilha = LIFO (Last In, First Out). Sempre remove o último elemento inserido.
❌ LIFO = Last In, First Out. Isso é a Pilha! Fila é FIFO.

2. Qual é a saída deste código?

pilha = [5, 10, 15, 20]
pilha.pop()
pilha.pop()
print(pilha)
  • [5, 10]
  • [15, 20]
  • [5, 10, 15]
  • [10, 15, 20]
✅ Correto! O primeiro pop() remove 20, o segundo remove 15. Sobram [5, 10].
❌ pop() remove do FINAL da lista (topo da pilha). Primeiro sai 20, depois 15. Sobra [5, 10].

3. Qual código inverte a string "DADOS" usando pilha?

texto = "DADOS"
pilha = []
for letra in texto:
    pilha.append(letra)
# O que pilha.pop() vai retornando?
  • S, O, D, A, D
  • D, A, D, O, S
  • S, A, D, O, D
  • D, O, D, A, S
✅ Perfeito! A última letra empilhada foi "S", então é a primeira a sair. Resultado: SODAD.
❌ Lembre: LIFO! O último empilhado ("S") sai primeiro. A ordem de saída é S→O→D→A→D.

4. Como a pilha é usada para desfazer ações (Ctrl+Z)?

  • Última ação primeiro
  • Primeira ação primeiro
  • Ação aleatória
  • Todas ações juntas
✅ Exato! Ctrl+Z desfaz a ÚLTIMA ação — comportamento LIFO da pilha.
❌ Desfazer = pop da pilha de ações. A última ação feita é a primeira a ser desfeita (LIFO).

5. O que a pilha da máquina guarda durante execução recursiva?

  • Frames de chamada
  • Valores de retorno
  • Endereços de memória
  • Variáveis globais
✅ Correto! Cada chamada recursiva cria um "frame" na call stack com variáveis locais e endereço de retorno.
❌ A pilha de execução guarda "frames de chamada" — cada frame tem as variáveis locais e o ponto de retorno daquela chamada.

6. Este código usa que estrutura?

estrutura = []
estrutura.append("A")
estrutura.append("B")
estrutura.append("C")
print(estrutura.pop())
  • Pilha (LIFO)
  • Fila (FIFO)
  • Deque
  • Lista ordenada
✅ Sim! append() + pop() = comportamento de Pilha (LIFO). Imprime "C" — o último inserido.
❌ append() no final + pop() no final = só mexe numa ponta = LIFO = Pilha!
