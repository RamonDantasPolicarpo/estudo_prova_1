Fila (Queue): Primeiro a Entrar, Primeiro a Sair

FIFO, por que list não serve, e como deque resolve tudo.

🧠 O Conceito

Uma fila é uma estrutura de dados onde o primeiro elemento inserido é o primeiro a ser removido. Isso se chama FIFO — First In, First Out.

Analogia do mundo real Pense na fila do banco ou do sistema de impressão. Quem chega primeiro é atendido primeiro. Não tem como o último da fila furar e ser atendido antes.

Compare com a Pilha que você acabou de aprender:

EstruturaRegraSiglaAnalogia
PilhaÚltimo entra, primeiro saiLIFOPilha de pratos
FilaPrimeiro entra, primeiro saiFIFOFila de banco

👁️ Visualizando

Entrada (append) Saída (popleft) ───────────► ───────────► ┌──────┬──────┬──────┐ │ 10 │ 20 │ 30 │ └──────┴──────┴──────┘ início fim append(40): ┌──────┬──────┬──────┬──────┐ │ 10 │ 20 │ 30 │ 40 │ └──────┴──────┴──────┴──────┘ popleft(): ┌──────┬──────┬──────┐ │ 20 │ 30 │ 40 │ → retorna 10 └──────┴──────┴──────┘

Entra pelo final, sai pelo início. Duas pontas diferentes — esse é o ponto-chave.

🚨 Por Que NÃO Usar list Para Fila

Você poderia fazer fila.pop(0) para tirar o primeiro elemento de uma lista. Mas isso é um gargalo:

pop(0) numa lista de 1000 elementos: [A, B, C, D, E, ... , Z] ↑ remove A Agora TODOS os 999 elementos precisam se mover uma posição: [B, C, D, E, ... , Z] ← ← ← ← ← ← ← ← Isso é O(n) — quanto maior a lista, mais lento!
⚠️ Do Kahoot (Pergunta 1, Kahoot 4) "Ao implementar uma fila FIFO com list, qual operação se torna gargalo?" → pop(0)
Porque remove do início e precisa mover todos os outros elementos.

✅ A Solução: collections.deque

deque (pronuncia-se "déck") significa Double-Ended Queue — fila de duas pontas. É uma estrutura feita de blocos ligados (não um array contíguo), então inserir e remover nas duas pontas é instantâneo (O(1)).

from collections import deque

# Criar fila vazia
fila = deque()

# Enfileirar (entrada no fim)
fila.append(10)    # deque([10])
fila.append(20)    # deque([10, 20])
fila.append(30)    # deque([10, 20, 30])

# Desenfileirar (saída do início)
primeiro = fila.popleft()   # primeiro = 10
print(primeiro)              # Saída: 10
🔶 Conexão com Java from collections import deque é como fazer import java.util.LinkedList;
fila.append(x) → queue.add(x)
fila.popleft() → queue.poll()
O conceito é o mesmo — a diferença é que em Python você precisa importar do módulo collections.

A combinação mágica: append + popleft

💡 Regra de Ouro Para FIFO com deque: append() coloca no fim + popleft() tira do início.
É a "entrada no fim, saída no início" — respeita a ordem de chegada naturalmente.

Compare as duas abordagens de estrutura:

EstruturaOperaçõesO que faz
Pilha (LIFO)append() + pop()Entra e sai pela mesma ponta (fim)
Fila (FIFO)append() + popleft()Entra por uma ponta, sai pela outra

💻 Exemplos dos Kahoots

Exemplo 1: Fila com adição e remoção

from collections import deque

fila = deque([10, 20, 30, 40])

fila.popleft()       # remove 10 (o primeiro)
fila.append(50)      # adiciona 50 no final

print(fila)           # deque([20, 30, 40, 50])

Saiu o 10 (primeiro da fila), entrou o 50 (no final). A fila "andou".

Exemplo 2: Fila com range

from collections import deque

fila = deque()

for i in range(1, 6):     # 1, 2, 3, 4, 5
    fila.append(i)

print(fila.popleft())      # 1 (primeiro que entrou)
print(fila.popleft())      # 2 (segundo que entrou)

Como identificar: é Pilha ou Fila?

Dica de prova Olhe para as operações de remoção:
• Usa pop() (remove do fim)? → Pilha (LIFO)
• Usa popleft() (remove do início)? → Fila (FIFO)
Ambas usam append() para inserir. A diferença está em onde remove.

🔄 Lista Circular e Escalonamento

Uma lista circular é como uma fila onde o último elemento aponta de volta para o primeiro, formando um ciclo. Ela permite percurso contínuo — útil em:

  • Escalonamento de processos: o sistema operacional alterna entre processos em ciclo (round-robin)
  • Buffers circulares: áudio, streaming — quando chega no fim, volta pro começo
Lista circular: ┌──── A ◄──── D ◄───┐ │ │ └───► B ────► C ─────┘ Percurso: A → B → C → D → A → B → C → D → ... Nunca termina — percurso contínuo!

  • 10

✅ Correto! popleft() remove o primeiro — o 10, que chegou primeiro (FIFO).
❌ popleft() remove do INÍCIO. O 10 entrou primeiro, então sai primeiro.

2. Qual operação é gargalo ao usar list como fila?

  • pop(0)
  • append()
  • popleft()
  • insert()
✅ Exato! pop(0) precisa mover todos os elementos — O(n). Por isso usamos deque.
❌ pop(0) é o gargalo! Remover do início de uma list desloca todos os outros elementos.

3. Qual combinação de métodos implementa FIFO com deque?

  • append + popleft
  • append + pop
  • appendleft + pop
  • insert + remove
✅ Perfeito! append (entra no fim) + popleft (sai do início) = FIFO.
❌ FIFO = entrada no fim (append) + saída no início (popleft). append+pop seria LIFO (Pilha).

4. Por que deque é mais indicado que list para operações nas duas pontas?

  • Blocos ligados
  • Array contíguo
  • Menor memória
  • Sintaxe simples
✅ Correto! deque usa blocos ligados internamente, permitindo O(1) nas duas pontas.
❌ A resposta é "blocos ligados". deque não é um array contíguo — usa blocos de memória ligados entre si, o que permite inserir/remover O(1) em ambas as pontas.

5. Como uma fila ajuda em sistemas de atendimento?

  • Organizar ordens
  • Inverter ordens
  • Eliminar duplicatas
  • Ordenar prioridades
✅ Sim! A fila organiza a ordem de atendimento — quem chegou primeiro, é atendido primeiro.
❌ A fila organiza ordens de atendimento, garantindo que quem chegou primeiro seja atendido primeiro (FIFO).

6. Você quer acesso LIFO simples — qual estrutura padrão de Python é mais direta?

  • List
  • Deque
  • Heapq
  • Tuple
✅ Correto! Para LIFO simples (pilha), list com append+pop é a mais direta em Python.
❌ Para LIFO simples, list é a resposta. append() e pop() no final são O(1) — não precisa de deque.

7. Como lista circular ajuda em escalonamento?

  • Percurso contínuo
  • Acesso aleatório
  • Ordenação rápida
  • Busca binária
✅ Perfeito! Lista circular permite percurso contínuo — o último aponta pro primeiro, ideal para round-robin.
❌ Lista circular permite percurso contínuo — ao chegar no fim, volta pro início sem parar.
