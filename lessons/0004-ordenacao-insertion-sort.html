Ordenação: sort(), Insertion Sort e Estabilidade

Como Python ordena, o que é estabilidade, e como funciona o Insertion Sort passo a passo.

🧠 Por Que Ordenar?

Você já viu na Lição 03: ordenar os dados permite busca binária, que é muito mais rápida. Mas ordenação também ajuda em:

  • Busca mais rápida em geral
  • Encontrar mínimo/máximo instantaneamente (primeiro e último elemento)
  • Eliminar duplicatas facilmente
  • Apresentar dados de forma organizada

💻 sort() e sorted() em Python

v.sort() — ordena no lugar

v = [7, 2, 9, 4, 1]
v.sort()            # modifica v diretamente
print(v)             # [1, 2, 4, 7, 9]
print(v[0])          # 1  (menor elemento)
print(v[-1])         # 9  (maior elemento)
Sobre v[-1] Em Python, índice negativo conta de trás pra frente:
v[-1] = último elemento, v[-2] = penúltimo.
Em Java não existe isso — você faria v[v.length - 1].

sorted() — retorna uma nova lista ordenada

v = [7, 2, 9, 4, 1]
nova = sorted(v)    # v continua [7, 2, 9, 4, 1]
print(nova)          # [1, 2, 4, 7, 9]
💡 sort() vs sorted() v.sort() → muda a lista original, retorna None
sorted(v) → cria nova lista, original inalterada
Em Java: Collections.sort(lista) é como v.sort() — modifica no lugar.
Do Kahoot 4: "Você recebe um gerador; o que sorted faz internamente antes de ordenar?"
→ Consome inteiro. sorted() precisa ver TODOS os elementos antes de ordenar, então primeiro transforma o gerador em uma lista completa na memória.

📏 len() — Contar Elementos

v = [2, 4, 6]
v.append(8)
v.append(10)
print(len(v))    # 5 (contou: 2, 4, 6, 8, 10)

len() retorna a quantidade de elementos. Em Java: list.size() ou array.length.

⚖️ Ordenação Estável

Uma ordenação é estável quando elementos com o mesmo valor mantêm sua ordem relativa original.

Exemplo: ordenar por nota (mantendo ordem de chegada para empates) Original: [Ana:8, Bia:7, Carlos:8, Dan:7] Estável: [Bia:7, Dan:7, Ana:8, Carlos:8] ↑ Bia veio antes de Dan → mantém ↑ Ana veio antes de Carlos → mantém INstável: [Dan:7, Bia:7, Carlos:8, Ana:8] ↑ Ordem dos empates pode mudar!
⚠️ Do Kahoot "Qual dessas ordenações seria mais estável?" → "Que mantém iguais juntos"
Estável = elementos iguais ficam na mesma ordem relativa em que estavam antes da ordenação.

O sort() do Python usa Timsort, que é estável.

🔄 Insertion Sort (Ordenação por Inserção)

É como organizar cartas na mão: você pega uma carta de cada vez e a insere na posição correta entre as que já estão ordenadas.

Ordenando [3, 1, 2] com Insertion Sort: Início: [3, 1, 2] ↑ já "ordenado" (só 1 elemento) Passo 1 (i=1): Pega o 1. Compara com 3. 1 < 3 → troca! [1, 3, 2] troca #1 Passo 2 (i=2): Pega o 2. Compara com 3. 2 < 3 → troca! [1, 2, 3] troca #2 Compara com 1. 2 > 1 → para! [1, 2, 3] Total: 2 trocas

Código do Kahoot (Kahoot 3, pergunta 10)

v = [3, 1, 2]
trocas = 0

for i in range(1, len(v)):   # i = 1, 2
    j = i

    while j > 0 and v[j] < v[j - 1]:
        v[j], v[j - 1] = v[j - 1], v[j]  # troca!
        trocas += 1
        j -= 1

print(trocas)
Sobre v[j], v[j-1] = v[j-1], v[j] Isso é um swap em Python — troca dois valores de posição em uma linha.
Em Java seria:
int temp = v[j]; v[j] = v[j-1]; v[j-1] = temp;
Python faz em uma linha porque suporta atribuição múltipla.

Rastreando passo a passo:

ijComparaçãoTroca?Vetor apóstrocas
11v[1]=1 < v[0]=3?Sim[1, 3, 2]1
10j > 0? Não → para—[1, 3, 2]1
22v[2]=2 < v[1]=3?Sim[1, 2, 3]2
21v[1]=2 < v[0]=1?Não → para[1, 2, 3]2

Resultado: 2 trocas.

⚠️ Atenção O Kahoot diz que a resposta é 9, mas pelo rastreamento correto de [3, 1, 2], são 2 trocas. É possível que o código no Kahoot tenha indentação diferente ou que a resposta original esteja errada. O importante é que você saiba rastrear a execução — é isso que cai na prova.

1. Qual é a saída?

v = [7, 2, 9, 4, 1]
v.sort()
print(v[0])
  • 1
  • 7
  • 9
  • 2
✅ Correto! sort() ordena para [1, 2, 4, 7, 9]. v[0] é o primeiro = 1 (menor).
❌ sort() ordena crescente: [1, 2, 4, 7, 9]. v[0] = primeiro elemento = 1.

2. Qual é a saída?

v = [7, 2, 9, 4, 1]
v.sort()
print(v[-1])
  • 9
  • 1
  • 7
  • 4
✅ Perfeito! Após sort: [1, 2, 4, 7, 9]. v[-1] = último = 9 (maior).
❌ sort() → [1, 2, 4, 7, 9]. v[-1] é o ÚLTIMO elemento = 9.

3. O que torna uma ordenação "estável"?

  • Mantém iguais juntos
  • Ordena mais rápido
  • Usa menos memória
  • Nunca falha
✅ Exato! Estável = elementos com mesmo valor mantêm a ordem relativa original.
❌ Estável = quando dois elementos são iguais, eles ficam na mesma ordem em que estavam antes.

4. Qual é a saída?

v.append(8)

✅ Correto! Começou com 3 elementos, adicionou 2 → total = 5.
❌ v começa com [2,4,6] (3 itens), append adiciona 2 mais → len = 5.

5. Qual efeito da ordenação em pesquisa de dados?

  • Busca mais rápida
  • Busca mais lenta
  • Mesma velocidade
  • Não tem efeito
✅ Sim! Ordenar permite busca binária, que é muito mais rápida que linear.
❌ Dados ordenados permitem busca binária → busca mais rápida!
