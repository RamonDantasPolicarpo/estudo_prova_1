Lição 03

Busca: Linear vs Binária

Quando cada uma é melhor, por que ordenar antes, e como o meio do intervalo funciona.

🔍 Busca Linear (Sequencial)

A busca mais simples: percorre um por um, do início ao fim, até achar o elemento ou acabar a lista.

Procurando o 40 em [10, 30, 40, 20, 50]: [10] → não [30] → não [40] → ACHOU! ↑ ↑ ↑ 1ª check 2ª check 3ª check Precisou de 3 comparações.

Vantagens:

  • Funciona em qualquer lista — ordenada ou não
  • Simples de implementar
  • Melhor quando tem poucos elementos

Desvantagem: no pior caso, verifica todos os elementos. Com 1 milhão de itens, pode precisar de 1 milhão de comparações.

⚡ Busca Binária

A busca binária é muito mais rápida, mas tem um pré-requisito obrigatório: a lista precisa estar ordenada.

⚠️ Regra de Ouro Busca binária só funciona em vetor ordenado. Sempre. Sem exceção.
É por isso que "ordenar antes de buscar permite busca binária" (Kahoot 1, pergunta 3).

Como funciona: dividir o problema pela metade

A ideia central é: olhe para o meio do intervalo. Se o alvo é maior, descarte a metade esquerda. Se é menor, descarte a metade direita. Repita.

Procurando 25 em [5, 10, 15, 20, 25, 30, 35]: Passo 1: inicio=0, fim=6 meio = (0+6)//2 = 3 vetor[3] = 20 20 < 25 → descarta esquerda → inicio = meio+1 = 4 [5, 10, 15, 20, 25, 30, 35] ↑meio ─descartado─ ───busca aqui─── Passo 2: inicio=4, fim=6 meio = (4+6)//2 = 5 vetor[5] = 30 30 > 25 → descarta direita → fim = meio-1 = 4 Passo 3: inicio=4, fim=4 meio = (4+4)//2 = 4 vetor[4] = 25 25 == 25 → ENCONTRADO! índice 4

Em vez de 7 comparações (linear), usou apenas 3. Com 1 milhão de itens, precisa de no máximo ~20 comparações!

💻 Código Python: Passo a Passo

Encontrando o meio do vetor

vetor = [2, 4, 6, 8, 10, 12, 14]

inicio = 0
fim = len(vetor) - 1   # 6 (último índice)
meio = (inicio + fim) // 2  # (0+6)//2 = 3

print(vetor[meio])           # Saída: 8 (o elemento do meio)
Sobre o // // é divisão inteira em Python — divide e descarta a parte decimal.
7 // 2 = 3 (não 3.5)
Em Java seria a divisão normal de int: 7 / 2 = 3.

Verificando se o meio é o alvo

vetor = [10, 20, 30, 40, 50, 60, 70]

inicio = 0
fim = len(vetor) - 1         # 6
meio = (inicio + fim) // 2    # 3

if vetor[meio] == 40:
    print("Encontrado")       # ← isso executa!
else:
    print("Não encontrado")

# vetor[3] = 40, que é igual a 40 → "Encontrado"

Quando o alvo NÃO está no meio: ajustar o intervalo

vetor = [5, 10, 15, 20, 25, 30, 35]
# Procurando o 25

inicio = 0
fim = 6
meio = (inicio + fim) // 2   # 3

# vetor[3] = 20, que é < 25
# Então o 25 está na DIREITA → mover inicio para frente
if vetor[meio] < 25:
    inicio = meio + 1        # inicio = 4

print(inicio)                 # Saída: 4
🔶 Conexão com Java A lógica é idêntica em qualquer linguagem:
int meio = (inicio + fim) / 2;
if (vetor[meio] < alvo) inicio = meio + 1;
else if (vetor[meio] > alvo) fim = meio - 1;
Python só troca / por // para divisão inteira.

💡 Resumo em uma frase Ordenar os dados permite busca binária, que é mais rápida que linear porque faz menos comparações — divide o problema pela metade a cada passo.

🔢 Quantos Vizinhos São Checados?

Na busca binária, a cada passo você compara o elemento do meio com o alvo e decide ir para esquerda ou direita. No máximo, 2 vizinhos são checados em cada nível de decisão (o meio e o próximo meio após o ajuste).

🎯 Teste Seu Conhecimento

1. Quando a busca binária é melhor?

  • Vetor ordenado
  • Vetor desordenado
  • Lista vazia
  • Lista encadeada
✅ Correto! Busca binária exige vetor ordenado — é o pré-requisito fundamental.
❌ Busca binária SÓ funciona em vetor ordenado. Sem ordem, não dá pra dividir pela metade.

2. Qual a saída?

vetor = [2, 4, 6, 8, 10, 12, 14]
inicio = 0
fim = len(vetor) - 1
meio = (inicio + fim) // 2
print(vetor[meio])
  • 8
  • 6
  • 10
  • 4
✅ Perfeito! fim=6, meio=(0+6)//2=3, vetor[3]=8.
❌ len=7, fim=6, meio=(0+6)//2=3. O elemento no índice 3 é 8 (contando: 2[0], 4[1], 6[2], 8[3]).

3. Por que ordenar antes de buscar?

  • Permite busca binária
  • Economiza memória
  • Facilita inserção
  • Reduz o vetor
✅ Exato! Ordenar é o que habilita o uso de busca binária, que é muito mais eficiente.
❌ A razão principal é permitir busca binária — que divide o problema pela metade a cada passo.

4. Qual a vantagem da busca binária sobre a linear?

  • Menos comparações
  • Menos memória
  • Mais simples
  • Funciona sempre
✅ Sim! Binária faz muito menos comparações porque divide pela metade a cada passo.
❌ A vantagem é fazer menos comparações. Ex: em 1 milhão de itens, linear pode precisar de 1M, binária precisa de ~20.

5. Quando a busca linear pode ser melhor que a binária?

  • Poucos elementos
  • Muitos elementos
  • Dados ordenados
  • Dados repetidos
✅ Correto! Com poucos elementos, o overhead da binária não compensa — linear é mais direta.
❌ Com poucos elementos, a busca linear é mais simples e rápida na prática — a binária tem overhead desnecessário.

6. Por que a busca binária usa o meio do intervalo?

  • Divide problema
  • Encontra mínimo
  • Ordena dados
  • Compara vizinhos
✅ Perfeito! Olhar o meio divide o problema pela metade — isso é a essência do "dividir e conquistar".
❌ O meio divide o problema pela metade — descarta 50% dos dados a cada passo.
