⚠️ Os seus 5 tropeços (é aqui que você erra, confira SEMPRE):
  1. len é função, não método. ❌ pilha.len() ❌ pilha.len → ✅ len(pilha)
  2. break solto dentro do for encerra o laço na 1ª volta. Só use break quando quiser mesmo parar.
  3. pop() em lista vazia dá erro. Sempre cheque antes: if pilha: (tem algo) ou if not pilha: (vazia).
  4. input() devolve TEXTO. Para número: int(input()).
  5. join só junta textos. Número precisa de str(x) antes. E print(lista) mostra os [ ]; para tirar, use join.

3. Pilha (LIFO) — "pilha de pratos"

Último que entra = primeiro que sai. Lista com append + pop.

pilha = []
pilha.append(10)
pilha.append(20)
pilha.append(30)
print(pilha.pop())        # 30
print(pilha)              # [10, 20]

while pilha:              # enquanto NÃO estiver vazia
    print(pilha.pop(), end=" ")   # end=" " não pula linha

Molde dos parênteses (1068 / 1069 / 1242)

Abre → append. Fecha → confere se tem algo, depois pop. No fim, se sobrou algo, está errado.

4. Fila (FIFO) — "fila do banco"

Primeiro que entra = primeiro que sai. deque com append + popleft. Nunca lista.pop(0) (lento: tem que deslocar todos).

from collections import deque     # NÃO esqueça o import!

fila = deque()                    # ou deque([10, 20, 30])
fila.append(10)                   # entra no FIM
fila.append(20)
print(fila.popleft())             # 10 (sai pelo INÍCIO)
print(fila[0])                    # espia o primeiro sem tirar

Molde 1110 (cartas): "tira da frente, joga no fim"

from collections import deque
n = int(input())
fila = deque()
for i in range(1, n + 1):          # 1..n
    fila.append(i)
descartadas = []
while len(fila) >= 2:
    descartadas.append(fila.popleft())   # joga fora o topo
    fila.append(fila.popleft())          # próxima vai pro fim
textos = []
for carta in descartadas:
    textos.append(str(carta))
print("Discarded cards: " + ", ".join(textos))
print("Remaining card:", fila[0])
fila.append(fila.popleft()) lê-se de dentro pra fora: 1º tira da frente, 2º põe no fim.

Insertion Sort (Kahoot 3) e contagem de trocas

v = [3, 1, 2]
trocas = 0
for i in range(1, len(v)):
    j = i
    while j > 0 and v[j] < v[j - 1]:
        v[j], v[j - 1] = v[j - 1], v[j]    # troca SEM variável temporária
        trocas += 1
        j -= 1
print(trocas)    # 2
Os 3 comandos dentro do while precisam estar indentados (no Kahoot estavam sem). Troca de vizinhos fora de ordem = Bubble/Insertion (1162 usa isso).
