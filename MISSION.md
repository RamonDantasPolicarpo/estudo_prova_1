# Mission: Passar na Prova 1 de Algoritmos e Estrutura de Dados

## Why
Ramon tem prova teórica HOJE (29/09/2026 às 15h) sobre Algoritmos e Estrutura de Dados no CEUB, 4º semestre. Ele precisa compreender os conceitos cobertos nos 4 Kahoots de aula (Pilha, Fila, Busca, Ordenação, bibliotecas Python) para responder corretamente a prova. A próxima prova será prática — essa é teórica.

## Success looks like
- Explicar com suas palavras o que é LIFO e FIFO e dar exemplos do mundo real
- Rastrear mentalmente a execução de código Python com `list`, `deque`, `heapq` e `bisect`
- Saber quando usar busca linear vs busca binária e por que ordenar antes
- Entender Insertion Sort e o conceito de estabilidade de ordenação
- Responder corretamente perguntas no estilo Kahoot sem hesitar

## Constraints
- ~2 horas de estudo (12:55 – 15:00)
- Prova teórica, não precisa escrever código, mas precisa interpretar código Python
- Já programa em Java, acha Python confuso por causa das bibliotecas com nomes diferentes
- Professor não explica conceitos, apenas mostra código — precisa preencher as lacunas conceituais

## Out of scope
- Escrever código Python do zero (será foco da próxima prova)
- Estruturas de dados avançadas (árvores, grafos, hash tables)
- Complexidade assintótica formal (Big O) — a menos que apareça nos Kahoots
